# Ejercicio personal — proyectos tecnológicos

**[Ver el PDF en el navegador](https://jorgoo-4.github.io/JorgeFARADAYavionica/Ejercicio-Personal/Proyectos_tecnologicos_Jorge_Gallego.pdf)**

El archivo pesa 9,4 MB y el visor de GitHub no lo muestra. El enlace de arriba lo abre directamente. También se puede descargar con el botón *Download raw file* de [`Proyectos_tecnologicos_Jorge_Gallego.pdf`](Proyectos_tecnologicos_Jorge_Gallego.pdf).

Es un resumen de:
- **Evaluación interna de Física (Bachillerato Internacional):** número de nodos de sustentación de un levitador acústico TinyLev de 40 kHz en función del voltaje.
- **Monografía de Física (Bachillerato Internacional):** la modulación Chirp Spread Spectrum en LoRa (alcance, sensibilidad y tolerancia al efecto Doppler según el factor de dispersión).
- **Sport Lines** (ganador del SIE Huesca 2025): líneas de pista deportiva reconfigurables con tinta electrónica.
- **Guiado para atletas con discapacidad visual** (SIE Huesca 2024): sensores piezoeléctricos y aviso sonoro por conducción ósea.

La monografía y la evaluación interna completas no están publicadas aquí: por las normas del Bachillerato Internacional las envío por correo electrónico.
